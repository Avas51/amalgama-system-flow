# Дизайн-идеи для Амальгамы: Системный Поток

## Контекст
Веб-приложение для управления режимами дня (Альфа, Бета, Гамма) и работы с амальгамой. Цель — создать интерфейс, который отражает переход энергии от статики (сжатый потенциал) к динамике (поток созидательной силы).

## Идея 1: Минималистичный Инженерный Интерфейс (Bauhaus + Киберпанк)

**Design Movement:** Bauhaus + Киберпанк. Функциональность как красота.

**Core Principles:**
1. Геометрическая точность — все элементы выстроены по сетке, без округлостей.
2. Контрастная типография — жирные заголовки (Courier New или IBM Plex Mono) vs. тонкий текст.
3. Монохромная палитра с одним ярким акцентом (неоновый голубой или зелёный).
4. Функциональные пустоты — пространство используется как инструмент, а не как украшение.

**Color Philosophy:**
- Фон: Чёрный (глубина, концентрация).
- Текст: Белый (чистота, ясность).
- Акцент: Неоновый голубой (#00D9FF) или электрический зелёный (#00FF41).
- Вторичный: Серый (для неактивных элементов).

**Layout Paradigm:**
- Вертикальный стек с чёткими разделениями.
- Левая колонка для выбора режима (как пульт управления).
- Правая колонка для отображения текущего режима и таймеров.
- Асимметричная сетка 3:7.

**Signature Elements:**
1. Пульт управления (три кнопки: Альфа, Бета, Гамма) с LED-индикаторами.
2. Цифровой счётчик времени (как на старых приборах).
3. Вертикальные линии, разделяющие секции (как провода в электросхеме).

**Interaction Philosophy:**
- Клик на режим → мгновенный переход (без анимации, как переключение канала).
- Таймер отсчитывает в реальном времени.
- Чек-листы отмечаются одним кликом.

**Animation:**
- Минимальные переходы (fade-in/fade-out за 200ms).
- Пульсирующий свет на активном режиме (как дыхание системы).
- Цифры таймера меняются с эффектом flip (как на табло).

**Typography System:**
- Заголовки: IBM Plex Mono, 700, 24px (режимы).
- Подзаголовки: IBM Plex Mono, 600, 16px (названия задач).
- Текст: IBM Plex Mono, 400, 14px (описания).
- Акцент: IBM Plex Mono, 700, 12px (таймеры).

**Почему это работает для Сергея:** Инженерный мозг мгновенно распознает логику пульта управления. Чёрный фон снижает когнитивную нагрузку. Неоновый акцент символизирует «сжатый потенциал», готовый к разряду.

## Идея 2: Органичный Поток (Biomorphic Design + Gradient Dynamics)

**Design Movement:** Biomorphic Design (живые, текучие формы) + Gradient Dynamics (плавные переходы энергии).

**Core Principles:**
1. Органичные кривые вместо углов — всё плывёт и трансформируется.
2. Градиентные переходы — цвета переходят друг в друга, как энергия.
3. Слои глубины — полупрозрачные элементы создают ощущение объёма.
4. Микро-анимации — всё движется, как дыхание.

**Color Philosophy:**
- Фон: Тёплый градиент (от глубокого синего #1a3a52 к золотому #d4a574).
- Текст: Кремовый (#f5f1e8).
- Акцент: Медный (#c86432) или янтарный (#ffa500).
- Вторичный: Полупрозрачные белые слои (rgba(255, 255, 255, 0.1)).

**Layout Paradigm:**
- Центральный круг (символ потока) с режимами, расположенными вокруг.
- Каждый режим — это сегмент круга, который расширяется при выборе.
- Таймеры и чек-листы появляются внутри расширенного сегмента.
- Асимметричная спираль (как спираль ДНК или вихрь энергии).

**Signature Elements:**
1. Центральный пульсирующий круг (сжатый потенциал).
2. Три орбиты вокруг круга (режимы Альфа, Бета, Гамма).
3. Волнистые разделители между секциями.
4. Плавающие частицы света (как энергия, движущаяся по системе).

**Interaction Philosophy:**
- Наведение на режим → режим светится и расширяется.
- Клик → режим становится активным, остальные затемняются.
- Таймер растёт как волна, заполняя сегмент.

**Animation:**
- Плавные переходы (ease-in-out за 600ms).
- Пульсирующий центральный круг (как сердцебиение).
- Частицы света дрейфуют по экрану (как энергия).
- Волны расходятся от активного режима.

**Typography System:**
- Заголовки: Playfair Display, 700, 28px (режимы).
- Подзаголовки: Lato, 600, 18px (названия задач).
- Текст: Lato, 400, 16px (описания).
- Акцент: Playfair Display, 700, 14px (таймеры).

**Почему это работает для Сергея:** Органичный дизайн отражает переход от статики к потоку. Градиенты символизируют плавное раскрытие сжатого потенциала. Микро-анимации создают ощущение живой системы, а не мёртвого механизма.

## Идея 3: Минимальный Дзен (Japanese Minimalism + Negative Space)

**Design Movement:** Japanese Minimalism (ма — концепция пустоты) + Negative Space Philosophy.

**Core Principles:**
1. Максимальная пустота — каждый элемент имеет смысл, ничего лишнего.
2. Монохромная палитра с одним цветовым акцентом.
3. Типографическая иерархия через размер и вес, не через цвет.
4. Дыхание пространства — элементы расположены с большим расстоянием друг от друга.

**Color Philosophy:**
- Фон: Светло-серый (#f8f8f8) или кремовый (#faf9f6).
- Текст: Тёмный серый (#2a2a2a).
- Акцент: Один цвет (например, тёплый коричневый #8b7355 или мягкий зелёный #7a9b7f).
- Вторичный: Светлый серый (#e8e8e8) для разделителей.

**Layout Paradigm:**
- Вертикальный стек с огромными промежутками.
- Каждый режим занимает всю ширину экрана (как отдельная страница).
- Горизонтальная навигация в виде точек (как слайдер).
- Центрированная композиция.

**Signature Elements:**
1. Три точки навигации (как дзенский символ трёх истин).
2. Большие, читаемые числа для таймеров.
3. Минимальные иконки (линии, не заполненные).
4. Пустое пространство как главный элемент дизайна.

**Interaction Philosophy:**
- Свайп влево/вправо для переключения режимов.
- Клик на точку для прямого перехода.
- Таймер обновляется без звука, только визуально.
- Чек-листы отмечаются с лёгким затемнением.

**Animation:**
- Плавные свайп-переходы (ease-out за 400ms).
- Мягкое затемнение неактивных элементов.
- Числа таймера меняются с лёгким масштабированием (scale 1.0 → 1.05 → 1.0).
- Нет никаких ярких эффектов.

**Typography System:**
- Заголовки: Noto Sans JP, 700, 32px (режимы).
- Подзаголовки: Noto Sans JP, 600, 18px (названия задач).
- Текст: Noto Sans JP, 400, 16px (описания).
- Акцент: Noto Sans JP, 700, 24px (таймеры).

**Почему это работает для Сергея:** Дзенский подход отражает идею «согласия с собой и миром». Пустота даёт мозгу отдых от стимуляции. Минимальный дизайн помогает сосредоточиться на сути — режимах и таймерах, без отвлекающих элементов.
